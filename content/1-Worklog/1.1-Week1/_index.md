### Week 1 Objectives

* Get acquainted with the First Cloud AI Journey - Workforce Bootcamp program.
* Learn the basics of the Amazon Web Services (AWS) ecosystem and Cloud Computing concepts.
* Complete 5 tasks on the AWS Skill Builder platform to earn a $100 AWS Credit, preparing resources for the upcoming weeks.

### Completed Tasks

1. **Kick-off and Orientation:** Attended the program orientation and learned about the final project requirements.
2. **AWS Overview:** 
   * Learned the differences between On-Premises and Cloud infrastructure.
   * Explored core services such as IAM (Identity Access Management), EC2 (Virtual Servers), S3 (Storage), and RDS (Database).
3. **Explore AWS Tasks:**
   * Completed required labs and quizzes assigned by the organizers.
   * Received the $100 AWS Credit promo code.
   * Applied the Credit to the personal AWS account and configured Billing Alarms to monitor usage and prevent unexpected charges.

### Outcomes

* Gained a solid understanding of Cloud concepts and AWS.
* The AWS account is now ready with $100 Credit to deploy the project without incurring personal costs.
