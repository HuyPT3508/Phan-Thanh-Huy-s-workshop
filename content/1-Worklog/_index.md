As part of the **First Cloud AI Journey - Workforce Bootcamp** program at **Amazon Web Services Vietnam**, I completed an 8-week internship with the goal of fully building and deploying **HCMUT Cinema** — a Cloud-Native cinema ticket booking system on AWS.

The internship was divided into 4 main phases:

* **Week 1:** Getting acquainted with the program, learning about AWS, and completing Explore AWS tasks to earn $100 credit.
* **Weeks 2 – 3:** Brainstorming project ideas, discussing within the team, and selecting the HCMUT Cinema project by evaluating older source codes.
* **Weeks 4 – 6:** Developing, improving, and debugging the system (Backend API, Frontend, DynamoDB seat locking, real-time Socket.IO).
* **Weeks 7 – 8:** Deploying the entire system to AWS (EC2, S3, RDS, DynamoDB, SES) and conducting End-to-End testing.
