### Mục tiêu Tuần 2

* Tổ chức các buổi họp nhóm để thảo luận về chủ đề đồ án.
* Phân tích và đánh giá các dự án mã nguồn mở (source code cũ) có sẵn để làm nền tảng phát triển.
* Đưa ra danh sách các dự án tiềm năng và so sánh ưu/nhược điểm.

### Các công việc đã thực hiện

1. **Họp nhóm (Brainstorming):**
   * Đề xuất nhiều ý tưởng khác nhau: Web TMĐT, Hệ thống quản lý thư viện, Hệ thống đặt vé rạp chiếu phim, v.v.
   * Phân tích tính khả thi của từng ý tưởng dựa trên thời gian và kỹ năng của các thành viên trong nhóm.
2. **Đánh giá các Source Code cũ:**
   * Tìm kiếm các repository trên GitHub liên quan đến các ý tưởng đã đề xuất.
   * Cài đặt thử nghiệm một số mã nguồn chạy trên môi trường Local.
   * Nhận định chung: Đa phần các source code cũ có kiến trúc nguyên khối (Monolithic), khó scale, thiết kế giao diện lỗi thời và thiếu các tính năng thời gian thực.
3. **Lựa chọn hướng đi:**
   * Thay vì làm lại từ số không, nhóm quyết định sẽ chọn một source code cũ có tiềm năng và tiến hành **Refactor (tái cấu trúc)** toàn bộ theo hướng Cloud-Native.

### Kết quả đạt được

* Thu hẹp danh sách ý tưởng xuống còn 2 dự án khả thi nhất.
* Thống nhất định hướng kỹ thuật chung cho toàn nhóm.
